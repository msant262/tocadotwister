# Toca do Twister 🐭

Site completo sobre criação de Ratos Twister no Brasil. Desenvolvido com React 19.2, TypeScript, Vite 7.2.7 e anime.js.

## 🎨 Design System

### Cores
- **Verde Sálvia** (#8FBC8F): Natureza, saúde e alimentação natural
- **Amarelo Mostarda** (#FFDB58): Energia, inteligência e aspecto lúdico
- **Branco Off-White** (#F8F9FA): Fundo limpo
- **Cinza Chumbo** (#2F4F4F): Textos e rodapés
- **Azul Bebê** (#E0FFFF): Detalhes de higiene e limpeza

### Tipografia
- **Títulos**: Fredoka
- **Corpo do Texto**: Lato

## 🚀 Tecnologias

- React 19.2
- TypeScript
- Vite 7.2.7
- React Router DOM 7.1.0
- anime.js 3.2.2

## 📦 Instalação

```bash
npm install
```

## 🛠️ Desenvolvimento

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 📄 Estrutura de Páginas

### Páginas Principais
- **Home**: Página inicial com visão geral
- **O Básico**: Informações para iniciantes
- **Habitação**: Guia sobre gaiolas e substratos
- **Alimentação**: Nutrição e alimentos permitidos/proibidos
- **Enriquecimento Ambiental**: Brinquedos, DIY e foraging
- **Brasil vs. Europa**: Comparação de padrões

### Ferramentas Interativas
- **Calculadora de Gaiola**: Calcula quantos ratos cabem em uma gaiola
- **Quiz**: Teste seus conhecimentos sobre Ratos Twister

### Artigos SEO
1. Rato Twister cheira mal? Como evitar odores na gaiola
2. Por que não posso ter apenas um rato Twister?
3. Lista completa de alimentos tóxicos para ratos
4. Quanto custa ter um rato Twister no Brasil? (Tabela de gastos)
5. Como apresentar um rato novo para o grupo (Introdução)
